## Deskripsi Repository
Repository ini dibuat sebagai dokumentasi kegiatan Day 1 Proyek Workshop yang membahas penggunaan AI dalam pengembangan aplikasi serta pengelolaan perubahan menggunakan Git dan GitHub.

## Tujuan Repository
Repository ini bertujuan untuk menyimpan hasil proyek workshop, mendokumentasikan proses pengembangan aplikasi, serta mempelajari penggunaan Git dan GitHub dalam version control dan kolaborasi.

## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi Workshop
Workshop membahas dua materi utama, yaitu Prompt Engineering dan Git/GitHub.

**Prompt Engineering** merupakan cara merancang instruksi agar AI dapat menghasilkan jawaban yang tepat, relevan, dan sesuai kebutuhan. Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format. Pemberian konteks dan instruksi yang spesifik dapat meningkatkan kualitas hasil AI.

**Git** merupakan version control system yang digunakan untuk melacak perubahan pada file. Git memiliki beberapa komponen utama, yaitu Working Directory, Staging Area, dan Git Directory.

**GitHub** merupakan platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi. Materi juga membahas penggunaan command Git seperti `git init`, `git add`, `git commit`, `git push`, dan `git pull`.

Pada praktik workshop, peserta membuat aplikasi sederhana bernama **Student Task Planner** menggunakan bantuan AI, kemudian mengelola perubahan proyek menggunakan Git dan GitHub.

### 2. Poin Penting dan Pengetahuan Baru
- Prompt AI yang spesifik dan memiliki konteks dapat menghasilkan output yang lebih sesuai.
- Struktur prompt terdiri dari Role, Task, Context, dan Format.
- Git digunakan untuk melacak perubahan pada proyek.
- GitHub digunakan untuk menyimpan repository secara online dan mendukung kolaborasi.
- Commit berfungsi untuk menyimpan perubahan pada repository.
- Push digunakan untuk mengirim perubahan ke repository GitHub.
- Pull digunakan untuk mengambil dan menggabungkan perubahan dari repository remote.
- Version control membantu mengelola perkembangan proyek secara terstruktur.

### 3. Pendapat Pribadi tentang Day 1 Proyek Workshop
Kegiatan workshop Day 1 memberikan pemahaman baru mengenai penggunaan AI dalam proses pengembangan aplikasi serta pentingnya Git dan GitHub dalam mengelola proyek. Materi Prompt Engineering membantu memahami cara memberikan instruksi yang lebih efektif kepada AI. Selain itu, praktik menggunakan Git dan GitHub memberikan pengalaman dalam menyimpan serta mengelola perubahan proyek. Materi ini bermanfaat sebagai dasar untuk mengembangkan proyek multimedia digital secara lebih terstruktur dan efisien.
